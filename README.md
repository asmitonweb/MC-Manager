# MC-Manager

This project is being hosted on the Windows machine under `E:\MC PC - Sandbox`.

## Windows deployment

Use the Windows-specific setup guide at `..\WINDOWS_SETUP.md`. The original `setup.sh`, `upgrade.sh`, and Azure deployment instructions are retained for reference only.

The Windows tray controller is located at `..\tray\`. It owns the Node manager process, while the Minecraft server core remains optional until its version, loader, mods, and plugins are selected.
